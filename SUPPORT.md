# Support

Use GitHub Discussions for usage questions, design discussion, and examples:

https://github.com/OneTesseractInMultiverse/restqs/discussions

Use GitHub Issues for reproducible bugs and focused feature requests:

https://github.com/OneTesseractInMultiverse/restqs/issues

Report suspected vulnerabilities through GitHub private vulnerability reporting:

https://github.com/OneTesseractInMultiverse/restqs/security/advisories/new

## Useful Context

Good reports include the crate version, Rust version, enabled features, RQS input, catalog definition, expected plan
shape, and actual error code. Do not include secrets or production data in public reports.

For adapter questions, include the target database dialect and the generated fragments. For security reports, use the
private advisory link above.
